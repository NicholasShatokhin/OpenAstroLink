# Documentation policy

> Current synchronized snapshot: **v0.2.10.58-buildfix9 (2026-09-09)**. See `STATUS.md`, `CURRENT_CHECKLIST.md` and `RELEASE_0.2.10.58.md` for current qualification boundaries.



> **Current development checkpoint:** v0.2.10.58-buildfix9. English remains canonical and Ukrainian mirrors remain required.

English is the canonical and normative documentation language for OpenAstroLink/OpenAstroSuite. Every human-readable project document should have a Ukrainian mirror under `docs/uk/` (or `README_UA.md` / `PROJECT_MANIFEST_UA.md` at repository root).

The English version wins if translations diverge. Ukrainian mirrors should preserve technical meaning, examples, warnings and maturity claims. API field names, driver IDs, C/C++ symbols, protocol constants and OpenAPI/JSON Schema identifiers remain English in both languages.

`docs/openapi.yaml` and JSON Schemas are machine-readable normative artifacts and are not translated field-by-field.


## Handoff synchronization rule — v0.2.10.57

A milestone/handoff package must synchronize current status, START_HERE, handoff, validation, roadmap, release note, site and both language trees. Historical release notes remain immutable except for factual errata.
