OPEN OBSERVATORY CONTROL

Одна ланка між астрономічним обладнанням і програмами.

OpenAstroLink — відкрита node-first система керування камерами, монтуваннями, фокусерами, астрометрією, автофокусом, гідуванням та автоматизованими сесіями.

Відкрити GitHubЯк це працює

Нативне обладнання

QHY, Canon EOS, EQDrive/Sky-Watcher, Gemini, ZWO ASI/EAF та compatibility backends у єдиній моделі керування.

Live acquisition

Live View, гістограма та auto-exposure assistant, scene/star autofocus і інструменти юстування шукача.

Астрометрія й автоматизація

Plate solving, adaptive urban capture, polar alignment, guiding і resource-locked асинхронні operations виконуються на node.

NODE FIRST

Керування залишається поруч з обладнанням.

OpenAstroLink node володіє hardware sessions і довгими operations. GUI та інтеграції працюють через HTTP/WebSocket, а Stellarium отримує живу позицію монтування і передає GOTO через Telescope Control bridge.

Камера / Монтування / Фокусер
              ↓
       OpenAstroLink node
          ↙          ↘
      GUI / API     Stellarium

Стан проєкту

Проєкт активно перевіряється на реальному обладнанні. Safety-gates для монтування зберігаються, доки конкретна механічна геометрія не відкалібрована й не пройшла HIL.
