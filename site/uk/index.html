ЩО ЦЕ І НАВІЩО

OpenAstroLink відділяє control layer обсерваторії від конкретного GUI.

Node володіє hardware sessions і operations, а OpenAstroSuite та сторонні програми є клієнтами. Це дозволяє native-first hardware control, headless/remote роботу, explicit cancellation/resource locks і science acquisition, який не залежить від preview rendering.

Чого нам не вистачало в наявних рішеннях? Не «кращого INDI чи ASCOM», а іншої архітектурної комбінації: node ownership + native drivers + workflow operations + independent science/preview data planes + відкритий protocol для стороннього ПЗ. Існуючі ecosystems залишаються compatibility targets.

v0.2.10.58 · HIGH-RATE CAMERA DATA PLANE

Live View має окремий acquisition/data plane, а pre-HIL audit прибрав зайву CPU/SDK роботу.

Capture і preview FPS незалежні: acquisition може працювати на camera max, preview default 60 FPS. Raw SER записується до droppable preview work; remote pixels ідуть binary OALV через /video, JSON events — через /events.

v0.2.10.58 прибирає stale QHY maxFps:30, робить OALV payload/source dimensions явними, декодує remote JPEG один раз і не дозволяє одному native physical camera займати Main та Guide одночасно. QHY steady-state Live також більше не питає mem length на кожному frame.

Static regression: 43/43 high-rate checks PASS, fresh Windows build уже qualified. Наступний HIL gate: camera-max + Preview 60, 5-10 хв SER без record drops та simultaneous main+guide Live на двох cameras.

Навігація вже працює; focus/exposure і ручний Wi-Fi control harden-яться за реальними виміряними збоями.

Free-point Sky Map GOTO фізично рухає реальне монтування, а target із Sky Map передається у Scheduler. QHY Live/Still та базовий рух Gemini focuser також HIL-positive.

OFFLINE NAVIGATION + FRAMING · v0.2.10.53

Навігація, рамки камер і preview мозаїки без повного planetarium.

Offline Sky Map підтримує catalogue/free-point GOTO. Після plate solve вона малює measured rotated camera rectangle із solved center, scale, image size та position angle. До solve окремо показуються predicted main/guide camera footprints з optical profile. Scheduler mosaic columns, rows, overlap і rotation можна preview як tile grid навколо selected target.

Якщо в Stellarium увімкнений optional Remote Control plugin, OpenAstroSuite передає solved, main, guide або mosaic-envelope frame у built-in rectangular FOV marker Stellarium. Standard Telescope Control лишається mount position/GOTO bridge.

Catalogue-object → Scheduler transfer уже підтверджений у running GUI. Усі mount actions і далі проходять через active OpenAstroLink backend; HIL-qualified direct-MC v9 geometry не дублюється і не змінюється.

NATIVE FIRST

Hardware ownership лишається біля hardware.

openastrolink-node володіє device sessions і long-running operations. Local/remote GUI працюють через HTTP/WebSocket; Stellarium — через telescope bridge. Native OAL drivers увімкнені за замовчуванням. INDI — opt-in для compatibility або hardware без native driver.
