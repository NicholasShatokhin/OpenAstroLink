NATIVE DRIVER SDK

Додавайте hardware в OAL без coupling до GUI.

Entry point для vendors і contributors, які реалізують native OAL drivers.

ABI v2 model

Native driver публікує stable driver identity, device enumeration, typed capabilities, health та invoke/cancel behaviour через OAL driver ABI. Camera drivers віддають frames через native frame callback path, а не великий JSON.

Почати тут

  • include/oal/driver_api.h — C ABI surface.
  • schemas/driver-manifest-v2.schema.json — manifest schema.
  • docs/uk/NATIVE_DRIVER_SDK.md — lifecycle, discovery, capabilities та examples.
  • drivers/reference_simulated/ — reference implementation.

Driver rules

Device-specific protocol/SDK code має лишатися в driver; capabilities замість vendor-name assumptions; cancellation де hardware дозволяє; clear health/failure; scheduler/autofocus policy лишається у Core.

Qualification

Public conformance/certification suite ще OAL 1.0 work. До цього third-party drivers мають pin-итися до відомого ABI/development checkpoint та надавати simulator/build/HIL evidence відповідно до hardware.
