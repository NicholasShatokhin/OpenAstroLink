GUIDE КОРИСТУВАЧА Й АСТРОНОМА

Керуйте node, а не набором незалежних device dialogs.

Guide для supervised use поточних OpenAstroLink workflows.

1. Два процеси

openastrolink-node володіє hardware. OpenAstroSuite — reference GUI, local або remote. Stellarium може окремо підключатися до telescope bridge.

2. Перший setup

  1. Запустити node, потім GUI.
  2. Refresh/discover devices та призначити roles.
  3. Налаштувати site й optical train.
  4. Перевірити короткий supervised motion/exposure до automation.

3. Capture і Live View

Capture FPS та preview FPS незалежні. Planetary SER пишеться до droppable preview work. Контролюйте captureFps, previewFps, recordFps, previewDropped, recordDropped.

4. Mount/navigation

GOTO, tracking, park/home, sync, abort, manual motion, Stellarium та built-in Sky Map. Не інтерпретуйте direct-MC axes вручну; proven v9 profile працює node-side і HIL-qualified.

5. Autofocus, exposure, Scheduler

Scene/star AF, sparse-scene auto exposure, DSO scheduler, planetary SER, mosaic та Polar Alignment мають різний qualification status. Current checklist — authority для HIL/pending.

6. Remote/safety

Використовуйте trusted LAN/VPN. Pre-1.0 ports не призначені для прямого Internet exposure. Найближча Beta supervised; unattended weather/roof/power safety — OAL 1.0.

Troubleshooting

Перевіряйте node startup, driver registry, discovery, потім interactive device operation до Scheduler. Для video відділяйте capture rate від preview transport і визначайте WebRTC чи /video fallback.
